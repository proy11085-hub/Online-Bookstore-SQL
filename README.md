# Online Bookstore Management & Sales Analysis

## Project Overview
This project involves designing and managing a relational database for an online bookstore using PostgreSQL.

The database stores information about books, customers and orders. SQL queries are used to retrieve, organise and analyse the stored information.

## Database Structure
The project consists of three tables:

1. **Books:** Stores book titles, authors, genres, prices and stock information.
2. **Customers:** Stores customer names, contact details and locations.
3. **Orders:** Stores customer purchases, order dates, quantities and transaction amounts.

## SQL Concepts Used
- SELECT and WHERE
- ORDER BY and LIMIT
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Aggregate Functions (SUM, AVG, COUNT)
- DISTINCT
- BETWEEN
- COALESCE

## Project Objectives
- Manage bookstore information through a relational database.
- Retrieve information using SQL queries.
- Analyse book sales and customer purchasing patterns.
- Examine stock levels and sales performance.
